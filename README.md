# 🎬 QuickTix – Movie Ticket Booking System

A responsive movie ticket booking website built using HTML, CSS and JavaScript. QuickTix allows users to explore movies, select cinema locations, choose showtimes and seats, and manage their bookings through a simple interface.

## ✨ Features

- Browse movies with posters and descriptions.
- Search movies by title.
- Filter movies by genre.
- View detailed movie information.
- Select cinema, booking date and showtime.
- Interactive seat selection with automatic price calculation.
- Book and cancel movie tickets.
- View all bookings in My Bookings.
- Store bookings using browser LocalStorage.
- Synchronize seat availability across browser tabs.
- Generate digital tickets with QR codes.
- Print tickets or save them as PDF.
- Responsive design for desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- QRCode.js

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the QuickTix folder in Visual Studio Code.
3. Install the Live Server extension if you haven't already.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## ⚠️ Project Limitations

- This is a frontend demonstration project.
- Booking information is stored in browser LocalStorage.
- No backend database or real payment gateway is integrated.
- QR codes are generated for demonstration purposes and are not validated by a cinema.
